## ٥.٢ خارطة التنفيذ (Implementation Roadmap)

| المرحلة | المحتوى | معيار الإنجاز | الحالة |
|---|---|---|---|
| **Phase 0 — Architecture** | القدرات · الهيكل · الوكلاء · الحوكمة · المخططات · سير العمل · المستودع | `rkpos validate` أخضر | ✅ **منجز (هذا الإصدار)** |
| **Phase 1 — MVP** | الوكلاء الثمانية · الوضع اليدوي · DOI · الفحوص · الحالة · اللوحة · CI | مشروعان كاملان عبر الخط بلا مراجع مختلقة | ✅ البنية جاهزة · ⏳ التشغيل التجريبي |
| **Phase 2 — Knowledge Base** | تعبئة MEM-AUTHOR (البصمة، المسرد) · استيراد الأعمال السابقة · قاعدة متجهات · RAG | Recall@10 ≥ 0.8 | ⏳ يحتاج قاعدة متجهات واختيار تضمين |
| **Phase 3 — Automation** | مفاتيح API لمزودين · `--live` · Zotero · مزامنة Drive · انحدار حي | ≥ 60% من الخطوات الروتينية آلية | ⏳ يحتاج حسابات |
| **Phase 4 — Advanced Agents** | تفعيل المتخصصين والمشرفين (النموذج B) · محكمون بشريون | دراسة سياسات + كتاب أكاديمي عبر الخط | ⏳ |
| **Phase 5 — Publishing Pipeline** | Pandoc/XeLaTeX · CSL · EPUBCheck · release.yml · قالب الناشر | QG6 أول كتاب | ⏳ يحتاج تثبيت الأدوات |
| **Phase 6 — Continuous Research** | AG-WCH مجدول · توصيات مرتبطة بالادعاءات | دورة رصد أسبوعية مستقرة | ⏳ |
| **Phase 7 — Digital Think Tank** | النموذج C · برامج بحثية · مجلس دائم · PostgreSQL · لوحة حية · أمن متقدم | محفظة ≥ 3 برامج | ⏳ |

## ٥.٣ قائمة النشر (Deployment Checklist)

**أ. المستودع والبيئة (Model A — اليوم)**
- [ ] `pip install -e ".[dev]"` ثم `rkpos validate` و`pytest -q` خضراء.
- [ ] حماية الفرع الرئيس في GitHub وتفعيل Actions.
- [ ] نسخ `.env.example` إلى `.env` وتعبئة `RKPOS_CONTACT_EMAIL`.
- [ ] مراجعة `knowledge-base/editorial/glossary.yaml` و`style_guide.md` واعتمادهما.
- [ ] مراجعة `memory/author/` وتعبئة البصمة الأسلوبية (L4).
- [ ] اختبار `rkpos verify-doi` على DOI معروف من مكتبة المؤلف.
- [ ] فتح مشروع تجريبي صغير (`--type op_ed`) وإكماله حتى الأرشفة.

**ب. التشغيل الحي (Model B)**
- [ ] `ANTHROPIC_API_KEY` + مزود ثانٍ للمراجعة؛ استبدال المعرفات النائبة في `config/model_routing.yaml`.
- [ ] تعبئة أسعار المزود الثاني في `config/pricing.yaml` من صفحته الرسمية.
- [ ] `rkpos eval --live` لوكلاء MVP؛ اعتماد التقارير (L4).
- [ ] Zotero API + مجموعة لكل مشروع.
- [ ] Pandoc + XeLaTeX + Noto Naskh Arabic؛ ملف CSL في `publishing/csl/`؛ بناء تجريبي.
- [ ] أسرار CI في GitHub Secrets؛ ضبط `RKPOS_LIVE_EVALS=true` حين يُراد الانحدار الحي في CI.

**ج. المعرفة والتوسع (Model C)**
- [ ] قاعدة متجهات + نموذج تضمين + مجموعة استعلامات ذهبية.
- [ ] جدولة `WF-RESEARCH-WATCH`.
- [ ] تفعيل AG-SEC وAG-AUT ومراجعة أمنية شهرية.
- [ ] خدمة فحص تشابه + سياسة الرفع.

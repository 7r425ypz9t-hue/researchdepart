# الطيار الآلي — الوكلاء يعملون وحدهم، والمؤلف يقرّر بنقرة

> عند تفعيل مشروع يمضي الوكلاء في خطته تباعاً بالمحرّك المختار (Claude Code أو API)، ولا يتوقفون إلا عند قرار يملكه المؤلف، فيعرضونه سؤالاً بخيارات جاهزة. النقر على الخيار هو القرار نفسه، ويُسجَّل باسم المؤلف في سجل القرارات.

## ٠. طريقتا العمل

| | **مباشر** (الافتراضي) | **موجَّه** |
|---|---|---|
| ما يحدث | يكتب الوكلاء العمل كاملاً ويضبطونه دون توقف | يتوقف الوكلاء عند كل قرار مرحلي |
| الأسئلة | **سؤال واحد** للاعتماد النهائي: اعتمد النص · اضبطه كله ثم اعرضه · أعد الكتابة بتوجيهي ✎ · سأراجع بنفسي | عند الإشكالية، والمخطط، وكل وحدة، والاعتماد النهائي |
| الاعتمادات المرحلية | تفويض يُسجَّل مرة واحدة في سجل القرارات | قراركم في كل مرة |
| خطوات تُتخطى | البحث والتحقق اللذان يحتاجان أدوات غير متاحة للوكيل؛ والمراجعات التي تُنتج تقارير لا تدخل النص؛ وإجراءات الإغلاق (القائمة في `config/autopilot.yaml`) | لا شيء |
| الضبط | تُضبط آلياً كل وحدة تجاوزت حدود الانضباط (أو بعدت عن صوتكم في الرأي والسرد) | بخياركم عند كل وحدة |
| الخطأ العابر | يُعاد مرة آلياً قبل أن يُسأل عنه | يُسأل عنه |
| بعد الاعتماد | يُنقل النص إلى المخطوط المعتمد مع ملف Word بهويتكم | كذلك |

مستوى «الهيكل»، الذي يكتب فيه المؤلف بنفسه، يبقى متوقفاً لقلمكم في الطريقتين.

## ١. من يقرّر ماذا

| مستوى الخطوة | ما يفعله الطيار |
|---|---|
| L1 ذاتي للوكيل | ينفّذ الخطوة ويغلقها باسم الوكيل |
| L2 موافقة المشرف | ينفّذها ويغلقها باسم المشرف المختص (أو المنسق) |
| L3 قرار المجلس | ينفّذها ويغلقها باسم المجلس |
| L4 موافقة المؤلف، أو خطوة أُسندت إلى المؤلف | **يتوقف ويسأل** بخيارات سريعة |
| المخطط والكتابة | يتولاهما محرّك بناء العمل بحسب مستوى الإنتاج، ويسأل عند اعتماد المخطط والوحدات |
| بلوغ الميزانية أو خطأ | **يتوقف ويسأل** |

**المحتوى لا أسماء الملفات:** يمرّر الطيار إلى كل خطوة نصوص المخرجات الثلاثة السابقة، والمسودة المجمّعة، وكرّاسة الرواية، وتوجيهكم إن وُجد. فالمدقق يدقق النص نفسه، والمحرر يحرر النص نفسه.

## ٢. الأسئلة وخياراتها (`config/autopilot.yaml`)

| السؤال | الخيارات |
|---|---|
| اعتماد خطوة | اعتمد وتابع · اعتمد مع ملاحظة ✎ · أعد التنفيذ بتوجيهي ✎ · أوقف لأراجع بنفسي |
| اعتماد المخطط | اعتمد المخطط وتابع · اقترح مخططاً آخر بتوجيهي ✎ · سأحرّر المخطط بنفسي |
| اعتماد وحدة (المستوى التدرّجي) | اعتمدها كما هي · واءم صوتها ثم اعتمدها · أعد كتابتها بتوجيهي ✎ · سأراجعها بنفسي |
| المسودة الكاملة (المستوى الكامل) | سأراجع الوحدات بنفسي · واءم صوت الوحدات المعلَّمة آلياً ثم اسألني · اعتمد الوحدات كلها كما هي |
| الدور لقلمكم (مستوى الهيكل) | سأكتبها الآن |
| بلوغ الميزانية | تابع رغم ذلك · أوقف |
| خطأ | أعد المحاولة · تخطَّ هذه الخطوة · أوقف |

الخيار الموسوم ✎ يحتاج ملاحظة أو توجيهاً، ويُحفظ التوجيه ويُمرَّر إلى الوكيل عند إعادة التنفيذ.

يمكن تحرير نصوص الخيارات في الملف نفسه. أما أسماء الإجراءات (`action`) فلا تُغيَّر.

**الإيقاف والاستئناف:** «أوقف» لا يُضيّع شيئاً، لأن الأسئلة تُشتق من حالة المشروع. ومتى استأنفتم أعاد الطيار طرح السؤال القائم.

زر «أوقف بعد الخطوة الجارية» لا يقطع خطوة في منتصفها، بل يوقف الطيار بعد إتمامها.

## ٣. في اللوحة
- **مشروع جديد ← ٥. التشغيل:** خانة «شغّل الوكلاء آلياً فور الإنشاء»، وهي مفعّلة افتراضاً، وتحتاج اختيار Claude Code أعلى الصفحة.
- **صفحة المشروع ← التشغيل الآلي:**
  - الحالة، وسجل «ما يجري الآن».
  - بطاقة السؤال بخياراتها، وزر «اقرأ النص المعني».
  - زرّا «شغّل/استأنف» و«أوقف».
- **الرئيسة ← بانتظار قراركم:** أسئلة المشاريع كلها مع خياراتها، فتقررون من الصفحة الأولى.

## ٣ب. الشاشة الجانبية: مراقبة النص والتدخل الطارئ
- **الكتابة الآن:** ما يكتبه الوكيل يظهر حرفاً بحرف، ومعه اسم الوكيل والخطوة.
- **⏹ إيقاف فوري:** يقطع الكتابة في لحظتها، ويُحفظ النص الجزئي، ويسألكم: أعد الخطوة بتوجيهي ✎ · أعد الخطوة كما هي · تخطَّها · أوقف.
- **ملاحظة للخطوات القادمة:** تُمرَّر لكل وكيل بعدها دون إيقاف العمل. وإن لم يكن الأمر طارئاً، فانتظروا نهاية الخطوة وأبدوا ملاحظتكم في سؤالها.
- **النصوص المنجزة:**
  - تشمل العمل مجمّعاً، والوحدات، ومخرجات كل خطوة.
  - التنزيل: **Word** (نسخة نظيفة أو بالوسوم) أو نصّي `.md`.
- كل ذلك يعمل في الخلفية دون أي نافذة سوداء.

## ٤. من سطر الأوامر
```bash
rkpos autopilot RKP-2026-0002 --engine claude_code                  # يعمل حتى أول سؤال
rkpos autopilot RKP-2026-0002 --answer approve                      # يجيب ويستأنف
rkpos autopilot RKP-2026-0002 --answer redo --note "ركّز على الإمارات"
rkpos autopilot RKP-2026-0002 --status
```

## ٥. حدود معلنة
- **الوكلاء يكتبون نصاً فقط**، فلا يتصفحون الإنترنت ولا يقرؤون ملفاتكم. خطوات مثل «استكشاف المصادر» و«التحقق من المصادر» تُنتج خططاً ومقترحات و`[NEEDS-EVIDENCE]`، لا مصادر متحققاً منها. التحقق الفعلي يبقى عبر أداة DOI أو بإدخالكم.
- **إغلاق خطوات L2 وL3 آلياً** يعني أن المشرف والمجلس هنا أدوار يؤديها النموذج نفسه، فاستقلال المراجعة منقوص ما لم يُضف مزود ثانٍ (`INDEPENDENCE_DEGRADED`).
- **كل نص يدخل المخطوط المعتمد يمر بقراركم.** واعتماد الوحدات «كما هي» خيار متاح، لكنه لا يعيد النص إلى أسلوبكم البشري؛ تلك مهمة قلمكم في المراجعة.

# لوحة تحكم «مِداد» — أيقونة سطح المكتب المتصلة بـ Claude

> لوحة محلية تعمل على جهاز المؤلف وحده، وتجمع في نافذة واحدة كل إجراءات تفعيل الوكلاء الخمسة والثلاثين في كل الحالات: داخل المشروع وخارجه، يدوياً أو آلياً، بالمحرّك الذي تختارونه. الحوكمة نفسها تسري: الوكيل يقترح، والمنظومة تتحقق، والمؤلف يقرّر.

## ١. ما الذي يعمل الآن وما الذي يحتاج شيئاً منكم

| البند | الحالة |
|---|---|
| اللوحة، وكل إجراءاتها، والاختبارات الآلية (5 اختبارات للوحة والمحرّك) | **تعمل** — اختُبرت في بيئة لينكس وفي متصفح آلي بلا أخطاء |
| محرّك Claude Code | **يعمل** — فُعّل به وكيل الكتابة فعلياً بعقد الأسلوب المعتمد (الكلفة المبلّغة 0.12 دولار) |
| أيقونة لينكس وبنية تطبيق ماك | **مختبرتان** بنيوياً في بيئة معزولة |
| أيقونة ويندوز | اختصار عادي إلى `pythonw.exe`؛ **لم يُختبر على جهاز ويندوز فعلي** — البديل المضمون: `py -m rkpos panel` |
| وضع الأيقونة على سطح مكتبكم | **يلزمكم**: لا يصل التشغيل السحابي إلى جهازكم؛ تُشغّلون ملف التثبيت مرة واحدة |
| مفتاح API | **اختياري**: Claude Code أو الوضع اليدوي يكفيان |

## ٢. التثبيت (مرة واحدة)

### ويندوز: أربع خطوات شفافة (بلا ملفات تنفيذية)
> أُلغي ملف التثبيت الموحّد لأن برامج الحماية عدّته «حصان طروادة» بطريقة بنائه (يقرأ نفسه وينزّل ويتجاوز سياسة التنفيذ). لا تعطّلوا الحماية ولا تستثنوا ذلك الملف؛ احذفوه.

1. **Python:** ثبّتوه من python.org (مثبّت موقَّع رسمياً)، مع تفعيل **Add python.exe to PATH**.
2. **المستودع:** نزّلوا https://github.com/7r425ypz9t-hue/researchdepart/archive/refs/heads/main.zip، وفكّوا ضغطه في «المستندات» (ينتج مجلد `researchdepart-main`).
3. **PowerShell العادي** (من قائمة ابدأ، دون صلاحيات المسؤول)، ثم الأوامر سطراً سطراً:
   ```powershell
   cd "$HOME\Documents\researchdepart-main"
   py -m pip install -e .
   tar -xzf "$HOME\Downloads\midad-private-backup.tar.gz"
   py -m rkpos install-icon
   ```
4. **Claude Code (اختياري):** من التوثيق الرسمي: `irm https://claude.ai/install.ps1 | iex`، ثم `claude` لتسجيل الدخول، ثم أعيدوا `py -m rkpos install-icon`.

الأيقونة اختصار عادي يشير مباشرة إلى `pythonw.exe -m rkpos panel`؛ لا ملف وسيط ولا أوامر مرمّزة.

### الطريق اليدوي

1. ثبّتوا **Python 3.10+** (في ويندوز: من python.org مع خيار *Add python.exe to PATH*).
2. نزّلوا المستودع: `git clone https://github.com/7r425ypz9t-hue/researchdepart.git` أو *Download ZIP* من GitHub.
3. ضعوا ملف النسخة الاحتياطية الخاصة `midad-private-backup.tar.gz` في مجلد المستودع أو في مجلد التنزيلات.
4. شغّلوا ملف التثبيت حسب نظامكم:
   - **ويندوز:** انقر مرتين على `launchers\install_windows.bat`
   - **ماك:** انقر مرتين على `launchers/install_mac.command` (أول مرة: زر يمين ← فتح)
   - **لينكس:** `launchers/install_linux.sh`
5. تظهر أيقونة **«مداد»** (قطرة حبر ذهبية على أزرق) على سطح المكتب.

يفعل ملف التثبيت ثلاثة أشياء: يثبّت الحزمة (`pip install -e .`)، ويستعيد الذاكرة الخاصة إن وجد النسخة الاحتياطية، ثم يُنشئ الأيقونة (`rkpos install-icon`). والإزالة بالأمر: `rkpos install-icon --remove`.

### الاتصال بـ Claude (اختر واحداً أو أكثر)
| المحرّك | ما يلزم | متى يُستعمل |
|---|---|---|
| **يدوي** | لا شيء | زر «انسخ وافتح Claude» ينسخ الحزمة كاملة ويفتح claude.ai، ثم تلصقون الرد في اللوحة |
| **Claude Code** | `npm install -g @anthropic-ai/claude-code` ثم الأمر `claude` مرة لتسجيل الدخول بحسابكم | التشغيل الآلي بحسابكم في Claude، بلا مفتاح في المستودع |
| **API** | `ANTHROPIC_API_KEY` في ملف `.env` | التشغيل الآلي بالمفتاح، وإضافة مزود ثانٍ لاستقلال المراجعة |
| **تلقائي** | — | المفاتيح أولاً، ثم Claude Code، ثم اليدوي |

ثبّتوا Claude Code **قبل** تشغيل ملف التثبيت، ليحفظ المشغّل مساره؛ وإلا أعيدوا `rkpos install-icon` بعد تثبيته.

### حالات التفعيل التي تغطيها اللوحة
1. **خطوة في خطة مشروع** بالمحرّك اليدوي: حزمة ← Claude ← لصق الرد ← تسجيل.
2. **خطوة في خطة مشروع** بمحرّك آلي: يكتب الوكيل المخرج مباشرة في `runs/<step>/output.md`.
3. **خطوة L4**: تتحول إلى «مهمة للمؤلف» ولا تُغلق إلا بإقراركم.
4. **تفعيل مباشر خارج المشاريع**: يُحفظ في `workspace/adhoc/` (غير متتبع).
5. **تفعيل مباشر داخل مشروع**: يُحفظ في `projects/<PID>/runs/ADH-…` ويرث سجلّ المشروع الأسلوبي.
6. **تقييم وكيل** بنيوياً أو حياً (للتعديلات عبر WF-AGENT-CHANGE).
7. **مراجعة مستقلة**: إن كان الكاتب والمراجع من عائلة Anthropic سجّلت المنظومة تحذير `INDEPENDENCE_DEGRADED`.

## ٤. الأمان والحوكمة
- الخادم يستمع على `127.0.0.1` وحده، ولا يصل إليه أحد من الشبكة.
- رمز عشوائي يتجدد مع كل تشغيل، ويُمرَّر في جزء الرابط بعد `#` فلا يُرسل إلى الخادم ولا يُسجَّل؛ وكل طلب بلا الرمز يُرفض (401)، وكل طلب بمضيف غير محلي يُرفض (403).
- لا تعرض اللوحة أي مفتاح؛ تكتفي بالإشارة إلى وجوده.
- القراءة من اللوحة محصورة في `projects/` و`workspace/` ولوحة القيادة.
- كل قرار L4 (اعتماد خطوة L4، ونقل نص إلى المخطوط المعتمد، وترقية إلى ذاكرة المؤلف أو المؤسسة، وتعديل عنصر معتمد) يتطلب خانة «أقرّ بصفتي المؤلف» في كل مرة، ويرفضه الخادم بدونها.
- محرّك Claude Code يُشغَّل بلا أدوات (`--tools ""`) ومن مجلد مؤقت فارغ: الوكيل يكتب نصاً، ولا يقرأ ملفاتكم ولا ينفذ أوامر.

## ٥. من سطر الأوامر (البدائل نفسها)
```bash
rkpos panel                                   # اللوحة
rkpos run-step RKP-2026-0002 --engine claude_code
rkpos activate AG-WRT "اكتب مسودة عمود عن…" --register essay --engine claude_code
rkpos activate AG-SRC "تحقق من هذا المرجع: …" --project RKP-2026-0002
rkpos eval AG-WRT --live                      # يتبع RKPOS_ENGINE
```

## ٦. حين يتعطل شيء
| العرض | الإجراء |
|---|---|
| الأيقونة لا تفتح شيئاً | شغّلوا `python -m rkpos panel` في الطرفية لرؤية الخطأ؛ السجل في `~/.rkpos/panel.log` (ماك ولينكس) |
| «Claude Code: غير مثبت» مع أنه مثبت | أعيدوا `rkpos install-icon` بعد تثبيته، أو ضعوا مساره في `RKPOS_CLAUDE_BIN` داخل `.env` |
| «انتهت صلاحية الجلسة» | أُعيد تشغيل الخادم؛ افتحوا اللوحة من الأيقونة من جديد |
| «الذاكرة الخاصة: غير موجودة» | فكّوا `midad-private-backup.tar.gz` في جذر المستودع |
| خطأ `claude exited …` | افتحوا الطرفية واكتبوا `claude` لتسجيل الدخول، ثم أعيدوا المحاولة |

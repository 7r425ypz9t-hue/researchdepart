# المرحلة الخامسة — نموذج الكلفة وحوكمتها

> **حالة الأرقام:** تقديرات `[ESTIMATE]` مبنية على افتراضات معلنة أدناه، لا على قياس فعلي. القياس الفعلي يبدأ مع أول تشغيل `--live` عبر `logs/cost_events.jsonl` و`rkpos cost-report`.
> **مصدر الأسعار:** `config/pricing.yaml` — أسعار Anthropic من مرجع Claude API المرفق بالأداة (نسخة مخزنة 2026-10-06): Opus 5.5 = 4 / 20، Sonnet 5.5 = 2 / 10، Haiku 5.5 = 0.10 / 0.50 دولار لكل مليون رمز (إدخال/إخراج). أسعار المزودين الآخرين غير معبأة عمداً (null) حتى يُتحقق منها.

## ٥.٤ حوكمة الكلفة (AG-CST)

| الآلية | التنفيذ |
|---|---|
| تسجيل كل استدعاء | `adapters/router.run` ← `cost.record` (نموذج، رموز، مشروع، وكيل، مرحلة) |
| التجميع | `rkpos cost-report --project <PID>` — حسب الوكيل/المرحلة/المشروع |
| الإنذار | 50% · 75% · 90% من سقف المشروع؛ تجاوز السقف = ESCALATION L4 |
| الحالة | `state.yaml → COST_USD` يُحدّث مع كل تحديث للحالة |
| التوفير | المهام البسيطة على T1 (Haiku)؛ التحقق والإنتاج على T2 (Sonnet)؛ التخزين المؤقت للبرومبت (البرومبتات ثابتة البادئة بطبيعتها) |
| الأحداث بلا سعر | تُسجّل `estimate: true` بلا رقم — لا اختلاق لأسعار |

# MEM-AUTHOR — ذاكرة المؤلف (AUTHOR_ONLY)

- الكتابة هنا للمؤلف وحده (أو بترقية معتمدة L4 عبر `rkpos memory-promote --approved-by HUMAN-AUTHOR`).

- ربط مقترح: بطاقة البصمة الأسلوبية في مهارة `style-fingerprint-majed-ar` تُعد المرجع الأول لهذه الطبقة.

# التحقق والاختبار

- `agent_selection_rules.yaml` — قواعد الاستدعاء الديناميكي للوكلاء.
- `rkpos validate` — سلامة المنظومة (مخططات، إحالات، أقل الامتيازات، تزامن الملفات المولدة).
- `rkpos eval` — فحص بنيوي لحزم الاختبار؛ `rkpos eval AG-XXX --live` تقييم حي بمحكّم مستقل (يستهلك رصيداً).
- `reports/` — تقارير التقييم الحي (غير متتبعة).
